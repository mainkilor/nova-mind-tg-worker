نصب روی Cloudflare

  1. در داشبورد Cloudflare یک Worker بسازید.
  2. محتوای nova-worker-channel-fixed.js را کامل جایگزین کد پیش‌فرض کنید و Deploy کنید.
  3. Bindingها را با همان نام‌های جدول بالا وصل کنید. توکن و رمز را Secret بگذارید، نه داخل فایل.
  4. یک‌بار این آدرس را باز کنید: https://YOUR_WORKER.workers.dev/set-webhook
  5. سلامت را چک کنید: /health باید bot: true و kv: true بدهد.
  6. در تلگرام /start بفرستید.

کانال و گروه

  • کانال عمومی: /channel @name 5 پست
  • یک پیام مشخص: لینک t.me/name/123
  • گروه یا کانال خصوصی: ربات باید عضو باشد. تاریخچهٔ قبل از عضویت خوانده نمی‌شود.

روشن کردن همین صفحه روی GitHub Pages

  1. یک ریپوی عمومی بسازید.
  2. همین سه فایل را در ریشهٔ ریپو بگذارید: index.html، INSTALL-FA.md، nova-worker-channel-fixed.js.
  3. Settings → Pages → Branch: main و پوشه / (root).
  4. هیچ توکن، .dev.vars یا رمز را آپلود نکنید.
